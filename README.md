# 📚 SomaHub — Learn Together

SomaHub is a mobile-friendly educational web app designed to support students and teachers.

## 🌟 Features

- 📝 **Learning Notes:** Write, save, and delete revision notes.
- 🎯 **Interactive Quizzes:** Answer questions and receive your score.
- 🏆 **Learning Goals:** Set and save a personal learning goal.
- 👩‍🏫 **Teacher Resources:** Save teaching resources and lesson ideas.
- 📱 **Mobile-Friendly Design:** Use SomaHub on phones, tablets, and computers.
- 🌐 **Basic Offline Support:** A service worker caches important website files.

## 🎓 Who Is SomaHub For?

**Students**
- Revise learning topics.
- Practise quizzes.
- Organise personal learning goals.

**Teachers**
- Store teaching ideas.
- Organise lesson resources.
- Support learning and revision.

## 💾 Data Storage

The current version saves notes, goals, and teacher resources in the browser's local storage on the device being used.

It does not yet include user accounts, a shared database, or automatic synchronisation between devices.

## 📦 Project Files

- `index.html` — Main website entry page for GitHub Pages.
- `somahub_mvp1.html` — Main SomaHub application source.
- `manifest.json` — Web app installation settings.
- `service-worker.js` — Basic caching and offline support.
- `README.md` — Project documentation.
